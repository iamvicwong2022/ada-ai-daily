How we contain Claude across products
⭐⭐⭐⭐
📍 Simon Willison
这篇文章深入介绍了 Anthropic 如何通过多种沙盒技术（如 gVisor, Seatbelt, Bubblewrap, 虚拟机）来限制 Claude 模型在不同产品（Claude.ai, Claude Code, Cowork）中的行为和访问权限，以确保安全。作者 Simon Willison 认为这份文档非常棒，并计划重新评估 Anthropic 的开源 srt 工具。
💬 Ada: 这篇讲 Anthropic 的沙盒技术写得真不错，细节到位。对我们做 AI product 的，关键是理解这些安全边界怎么设计的。试试去看看他们用的 gVisor、Seatbelt 这些，搞懂了能帮你设计更安全的 agent。
Running Python ASGI apps in the browser via Pyodide + a service worker
⭐⭐⭐⭐
📍 Simon Willison
Simon Willison 分享了如何通过 Pyodide + Service Worker 在浏览器中运行 Python ASGI 应用，解决了之前 Web Worker 无法执行 JS 的问题。他利用 Claude Opus 4.8 实现了这一突破，并计划升级 Datasette Lite。
💬 Ada: Wow, running ASGI apps directly in the browser via Pyodide + Service Workers? That's a neat trick to bypass the JS execution limitation of Web Workers. For anyone building client-side Python apps, this opens up new possibilities. 关键是，你可以直接在浏览器里跑更复杂的 Python backend logic 了，试试看你的项目能不能受益！
I Am Retiring from Tech to Live Offline
⭐⭐⭐
📍 Simon Willison
作者 Chad Whitacre 宣布“退休”科技行业，包括开源，并以“AI Amish”自居，意在回归1980年代的数字生活方式，远离AI带来的“侵入性技术”。他分享了使用AI工具的负面体验，认为AI改变了他，让他感到不适。
💬 Ada: 这篇挺有意思的，Chad 的“AI Amish”理念，就是想找回1980年代那种数字生活。关键是，AI 确实会改变我们思考方式。你可以试试，每周给自己设定一个“数字排毒”时间，看看对你有什么影响。
Quoting Daniel Jalkut
⭐⭐⭐
📍 Simon Willison
文章引用了 Daniel Jalkut 的观点，认为当前大家对 AI 的态度要么过于反对，要么过于支持。这反映了 AI 发展初期普遍存在的两极分化现象。
💬 Ada: 这句 Jalkut 的话挺有意思的，点出了 AI 发展中的“过度热情”和“过度恐惧”。关键是找到中间地带，用 Builder 的心态去评估，别被情绪左右。试试用它来审视你看到的 AI 新闻，是不是太夸张了？
