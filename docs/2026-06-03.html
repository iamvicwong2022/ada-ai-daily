Microsoft's new MAI models
⭐⭐⭐⭐
📍 Simon Willison
微软发布了两款新的 MAI LLMs：MAI-Thinking-1 (35B) 和 MAI-Code-1-Flash (5B)。特别之处在于其较低的参数量，同时 MAI-Thinking-1 在盲测中优于 Sonnet 4.6。两款模型均使用微软自有、合规授权的数据训练，而非第三方模型蒸馏或未经授权的爬取数据。
💬 Ada: 微软这次的 MAI 模型挺有意思，参数量不大但效果不错，而且强调了数据来源的合规性。关键是，这可能意味着更低成本、更可控的定制化模型。你可以关注一下他们后续关于“appropriately licensed data”的细节，这可能是个大方向。

Pasted File Editor
⭐⭐⭐⭐
📍 Simon Willison
Simon Willison 分享了一个名为 Pasted File Editor 的原型工具，模仿了 Claude.ai 的大文本粘贴功能，允许直接打开文件（包括图片）或拖拽文件到文本区域。这个工具是用 JavaScript 和 Codex Desktop 构建的。
💬 Ada: 这个 Pasted File Editor 的 idea 挺有意思的！模仿 Claude 的大文本粘贴功能，直接把文件当 attachment。关键是它支持图片预览，还能直接拖拽文件。你可以试试看能不能把这个思路应用到你现在的产品里，提升用户处理大量信息或文件的体验。
micropython-wasm 0.1a0
⭐⭐⭐⭐
📍 Simon Willison
Simon Willison 发布了 micropython-wasm 0.1a0，这是一个实验性项目，将 MicroPython 编译为 WebAssembly (WASM)，并使用 wasmtime 来执行代码。这为在沙箱环境中运行 Python 代码提供了新的可能性。
💬 Ada: 这个 micropython-wasm 0.1a0 很有意思！如果你也在搞沙箱或想在浏览器里跑 Python，可以研究下。关键是 WASM + Python 的组合，看看能不能给你的项目带来新思路。试试看能不能集成到你现有的 Web 应用里？

Introducing Segment Anything: Working toward the first foundation model for image segmentation
⭐⭐⭐⭐⭐
📍 Meta Research
Meta Research 介绍了 Segment Anything，一个旨在成为首个图像分割基础模型的项目。它引入了一个全新的 Promptable Segmentation 模型，能够根据文本、点、框等多种提示生成分割结果。
💬 Ada: 这个 Segment Anything model 简直是图像处理的 game changer！想想看，以后做任何 CV 任务，都可以直接用它来做 segmentation，省多少事儿？关键是，它支持多种 prompt，非常灵活。试试用它来加速你的数据集标注流程，绝对效率翻倍！
